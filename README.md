# Space2026 🚀

A Spring Boot application built using space-related data and APIs.

## Features

* Space-related data
* External API integration
* REST APIs
* Spring Boot backend
* Maven project

## Tech Stack

* Java
* Spring Boot
* Spring Web
* Maven
* REST APIs

## Getting Started

Clone the repository:

```bash
git clone https://github.com/khushnumaparween/space2026.git
cd space2026
```

Run the application:

```bash
mvn spring-boot:run
```

Or on Windows:

```bash
mvnw.cmd spring-boot:run
```
